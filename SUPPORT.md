# Support

OpenLegalCore Word Connector is a source-only beta. It is provided under the
[Apache License 2.0](LICENSE) without warranty or an included support service.
Word for the web is the verified client; Word for Windows and Word for Mac are
not yet tested or supported.

## Choose the right channel

| Need | Channel |
| --- | --- |
| Installation, configuration or known limitation | Start with the documentation below |
| Reproducible connector defect | Open a [GitHub issue](https://github.com/OpenLegalCore/olc-word-connector/issues) using synthetic data |
| Suspected vulnerability | Follow [SECURITY.md](SECURITY.md); never open a public issue |
| Integration, training or operated deployment | See [Partnerships and services](PARTNERSHIPS.md) |

## Self-service documentation

Start with:

- [Installation and deployment](docs/INSTALLATION.md)
- [User guide](docs/USER_GUIDE.md)
- [Troubleshooting](docs/TROUBLESHOOTING.md)
- [Compatibility and limitations](docs/COMPATIBILITY_AND_LIMITATIONS.md)

For a reproducible defect, include the exact version or commit, Word client and
browser, manifest/build target, expected and actual behavior, minimal steps
and sanitized error code. Search existing issues before opening a duplicate.

Do not post client documents, selected text, generated legal answers, personal
data, credentials, cookies, private host details, or access-controlled URLs.

## Security reports

Do not report a suspected vulnerability in a public issue. Follow
[SECURITY.md](SECURITY.md) and email
[security@openlegalcore.org](mailto:security@openlegalcore.org).

## Partnerships and operated deployments

Backend integration, deployment, training, and commercial support are separate
from the source license. See [PARTNERSHIPS.md](PARTNERSHIPS.md).

## Support boundary

A source release, issue tracker response or community discussion does not create
a service level, uptime commitment, legal-advice relationship or warranty.
Operators remain responsible for their backend, identity, infrastructure,
legal data, privacy notices and incident response.
