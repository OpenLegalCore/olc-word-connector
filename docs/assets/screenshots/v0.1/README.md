# v0.1 documentation screenshot assets

This directory contains the twelve curated images used by the
[bilingual product gallery](../../../SCREENSHOTS.md):

- `en-US/` contains six English-interface workflow images;
- `sl-SI/` contains the six matching Slovenian-interface images;
- matching numbers identify the same workflow state in both locales.

All images were captured in Word for the web against private staging on
4 September 2026. The visible `STAGING` label is intentional. Select a preview
in the gallery to open the original full-size image.

Screenshots illustrate the interface. They are not proof of legal correctness,
exhaustive retrieval, public-service availability or platform support.
